# 🧩 Projeto Vida Plena

O **Projeto Vida Plena** é um sistema modular desenvolvido em **Java**, voltado à gestão de uma clínica de saúde integrada, com módulos para:
- Clínica médica 🏥  
- Eventos 💬  
- Restaurante 🍽️  
- Relatórios 📊
